# Smart Recipe Search Engine 🍳

An intelligent recipe search system based on:

- TF-IDF Information Retrieval
- Cosine Similarity
- Popularity Ranking
- Streamlit Interactive UI

## Features

- Search recipes by ingredients
- Ingredient matching
- Recipe ranking
- Calorie filtering
- Popularity-based ranking
- Recipe images display

## Project Pipeline

1. Build clean dataset
2. Download recipe images
3. Build TF-IDF search index
4. Run Streamlit application

## Run

```bash
streamlit run app.py
